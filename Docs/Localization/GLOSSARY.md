# Hereabouts: translation glossary

The words below are used the same way on every screen, in Siri answers, widgets, notifications and the App Store listing (M63). Change one only by changing it everywhere.

## Never translated

- **Hereabouts**: the app name. In Portuguese it takes the article ("o Hereabouts"); in French and Spanish it stands alone.
- **Pro**: the paid plan. "Hereabouts Pro" stays whole.
- **${applicationName}**, **${thing}**, **${place}**, **${name}** in Siri phrases: placeholders filled by the system.
- **ERASE**: the word typed to confirm erasing the notebook. The check compares against English, so every language asks for ERASE.
- Prices: never written. The App Store supplies them.

## English (U.K.) spelling changes

Acknowledgements, cancelled, licence (but SIL Open Font License, a proper name), any more, any time, towards, organiser (listing only). Demo names: My flat, Mum’s house, Hall cupboard.

## Things that stay English on purpose

- Voice capture and the "Name in Place" typed shortcut understand English only. The listing says so in each language.
- Box label PDFs use the strings above; the support email subject and CSV column headers stay English so support can read them.
